# 1.0 Requirements

## 1.1 Purpose

Automate ingestion, transcription, analysis, and content generation of sermons for structured outputs and book creation.

## 1.2 Design Principles

* Single shared sermon processor
* Deterministic outputs
* Config-driven
* No duplicated logic
* Simplicity (MVP)

## 1.3 Content Classification

* SERVICE
* SCRIPTURE_READING
* SERMON
* BENEDICTION

## 1.4 Feature Tags (SERMON ONLY)

* HUMOR
* SARCASM
* ANALOGY
* CURRENT_EVENT
* BIBLICAL_EVENT
* POLITICAL_EVENT
* NATURAL_DISASTER

## 1.5 Structure Detection

* intro (prayer)
* points
* subpoints
* side notes
* analogies (main vs supporting)
* conclusion
* benediction marker

## 1.6 Doctrine Alignment

* aligned
* implicit
* ambiguous
* conflict
* contradiction

## 1.7 Viewpoints

* endorsed
* rejected
* uncertain

Rule: reinforce only endorsed/rejected

## 1.8 Entities

* FAMILY (Marsha)
* STAFF (Joe, Tim)
* PASTOR
* AUTHOR / COMMENTATOR
* BIBLICAL_PERSON

## 1.9 Series Model

* BOOK
* PERSON
* TOPICAL
* NONE

Rules:

* skip non-series (if enabled)
* log skipped dates

## 1.10 Outputs

* transcript
* church notes
* analytical outline
* doctrine report
* improvement log
* optional: book content

## 1.11 Voice Per Output

* LISTENER_THIRD_PERSON
* EDITORIAL_THIRD_PERSON
* PASTOR_FIRST_PERSON
* DIRECT_TO_READER
* FORMAL_NEUTRAL

## 1.12 Special Rules

* detect opening prayer
* detect scripture reading (separate)
* detect benediction (mark only)
* distinguish current vs biblical events
* mark unintelligible audio

## 1.13 Source Constraints

* Boxcast changes over time
* YouTube temporary
* Website preferred
* full service not stored due to copyright

## 1.14 Rerun Strategy (MVP)

* full rerun only
* new version generated
