# Sermon Analyzer — Canonical Transcript Schema

## Purpose

The canonical transcript schema is the normalized internal format for a sermon transcript.

It is the output of:

* transcription
* transcript normalization

It is the input to:

* structure analysis
* doctrine/reference analysis
* outputs
* transcript validation/reuse checks


---

## MVP Design Goals

The MVP schema should:


1. support transcript reuse
2. support segment-based analysis
3. remain provider-neutral
4. be easy to validate
5. avoid fields we do not yet need


---

  "schemaVersion": "1.0.0",

## Required Top-Level Fields

* `schemaVersion`
* `artifactType`
* `sermonId`
* `transcriptVersion`
* `createdAt`
* `provider`
* `source`
* `language`
* `fullText`
* `segments`


---

## Field Definitions

### `schemaVersion`

Type: string

Tracks the transcript schema version.

### `artifactType`

Type: string

Fixed value:

```json
"CANONICAL_TRANSCRIPT"
```

### `sermonId`

Type: string

Deterministic sermon identity. Must match registry.

### `transcriptVersion`

Type: integer

Starts at `1`. Increment only if transcript is deliberately regenerated.

### `createdAt`

Type: ISO datetime string

When the canonical transcript artifact was created.

### `provider`

Type: object

Required fields:

* `name`
* `model`

### `source`

Type: object

Required fields:

* `sourceType`
* `sourceUrl`
* `mediaUrl`

### `language`

Type: string

Default to `"en"` for MVP if language is missing.

### `fullText`

Type: string

Required. Must not be empty for a valid transcript.

### `segments`

Type: array

Required. Preferred for all MVP transcripts.

## Segment Schema

```json
{
  "segmentId": "seg-0001",
  "start": 0.0,
  "end": 4.2,
  "speaker": "UNKNOWN",
  "text": "Good morning church.",
  "flags": []
}
```

### Required Segment Fields

* `segmentId`
* `start`
* `end`
* `speaker`
* `text`
* `flags`

### Segment Rules

#### `segmentId`

Type: string

Format:

* `seg-0001`
* `seg-0002`

Sequential and zero-padded.

#### `start`

Type: number

Segment start time in seconds.

#### `end`

Type: number

Segment end time in seconds. Must be `>= start`.

#### `speaker`

Type: string

Default:

```json
"UNKNOWN"
```

#### `text`

Type: string

Required. Trimmed. Must not be empty.

#### `flags`

Type: array of strings

Allowed MVP values:

* `UNINTELLIGIBLE`
* `LOW_CONFIDENCE`
* `INTERRUPTION`
* `NOISE`


---

## Validation Rules

A canonical transcript is valid for MVP if:

### Top-level

* `schemaVersion` exists
* `artifactType == CANONICAL_TRANSCRIPT`
* `sermonId` exists
* `transcriptVersion >= 1`
* `createdAt` exists
* `provider.name` exists
* `provider.model` exists
* `source.sourceType` exists
* `language` exists
* `fullText` exists and is not empty
* `segments` exists and is an array

### Segment-level

For each segment:

* `segmentId` exists
* `start` is numeric
* `end` is numeric
* `end >= start`
* `speaker` exists
* `text` exists and is not empty
* `flags` is an array


---

## Normalization Rules

### Text normalization

* trim leading/trailing whitespace
* normalize repeated spaces
* preserve sentence content
* do not rewrite meaning

### Segment normalization

* generate deterministic `segmentId`
* ensure timestamps are numeric
* default missing speaker to `"UNKNOWN"`
* default missing flags to `[]`


---

## Intentionally Excluded from MVP

Do not add these yet:

* raw provider response blob
* confidence scores at transcript level
* word-level timestamps
* advanced diarization
* checksum/hash
* content section detection
* doctrine data
* scripture references
* review summary block
* workflow version
* prompt version
* config version

These belong in other artifacts or state records.


---

## Registry Relationship

The registry should reference this artifact, not duplicate it.

Registry should store:

* `transcriptStatus`
* `transcriptVersion`
* `transcriptCreatedAt`
* `transcriptProvider`
* `transcriptArtifactRef`

Registry should not duplicate:

* `fullText`
* `segments`
