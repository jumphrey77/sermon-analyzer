# 3.1 Discovery Rules

## Purpose

Define how the system discovers new sermons from sources.

## Supported Sources

* website
* boxcast
* youtube

## Source Priority


1. website
2. boxcast
3. youtube

## Discovery Modes

* days
* service_count
* date_range

## MVP Behavior

* fetch candidates
* normalize metadata (title, date, URL)
* filter by window
* compare with registry
* process only new sermons

## Source Notes

### Website

* preferred source
* clean metadata
* sermon-focused

### Boxcast

* may contain full service or sermon only
* must handle variation

### YouTube

* fallback source
* may contain temporary live streams

## Duplicate Detection

Match on:

* URL
* title + date
* source ID

## Registry Check

* skip already processed sermons
* log skip reason if needed

## Series Filtering

* include only sermons in active series
* skip others if configured

## Manual Override

* explicit backlog overrides discovery

## Failure Handling

* log error
* do not corrupt registry
* retry next cycle

## Future Enhancements

* source adapters
* confidence scoring
* fingerprinting
